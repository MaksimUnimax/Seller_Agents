# packages/marketplaces

Отдельные provider adapters. Общая инфраструктура принадлежит bridge-core; endpoints/auth/семантика принадлежат конкретному адаптеру.

Текущее состояние: Ozon adapter используется development carrier; WB internal adapter загружается в его worker и проверен с локальными application ports. Прикладной маршрут WB ещё не подключён. См. [D2.3](../../docs/development/EXTENSION_WB_ADAPTER.md).
Границы: [архитектура](../../docs/architecture/OVERVIEW.md), [размещение](../../docs/architecture/REPOSITORY.md), [текущий статус](../../docs/STATUS.md).
