## Correction

The rejected candidate located every Standard contour through synthetic
`hf-*`/`data-hf-*` markers generated by its own fixture. This correction adds
the immutable local `CHATGPT_STANDARD_H3_V2` profile in
`apps/health-runner/src/standard-h3-profile.ts`. The strategy uses its typed
locator builders and the existing B2 engine; no caller selector, URL, script,
raw prompt, raw response, or remote override is accepted.

The deterministic fixture now models the profile's real ChatGPT semantics:
the bounded document root plus `/c/<UUID>` route/canonical identity, `#prompt-textarea` and the
accepted prompt fallbacks, `button[data-testid="send-button"]`,
`button[data-testid="stop-button"]`, `section[data-turn="assistant"]`,
`data-turn-id`, writing-block/CodeMirror/`#code-block-viewer`/`pre > code`
surfaces, and native Copy buttons labelled `Copy`/`Копировать`. Fixture
bookkeeping is limited to orthogonal `data-fixture-*` attributes and server
counters; the production strategy never queries them.
