## Proven defect

C11_CONVERSATION_IDENTITY is required CORE. Its Health catalog primary strategy is CONVERSATION_IDENTIFIER and its declared fallback is CONVERSATION_URL_IDENTITY.

Both current Standard and Work validateBridgeSurfaces implementations actually evaluate CONVERSATION_URL_IDENTITY as the fallback. On success they correctly record primary FAIL + URL fallback PASS + selected fallback + APPROVED_EQUIVALENT.

On identity failure both strategies currently record URL fallback FAIL and still set fallbackQuality=APPROVED_EQUIVALENT, but set selectedStrategyId=null. H3ContourObservationSchema requires a selected fallback whenever fallbackQuality is non-NOT_APPLICABLE. The observation construction throws; each strategy's #safe catches that exception and returns bare fail() with no observations. The generic H3 engine therefore loses the complete C09–C12 bridge-validation provenance instead of retaining a required-core C11 failure.

This is the remaining B5 blocker after the accepted TIME-R1 chronology fix.
