### Scripted Page Proxy — exact contract

Inputs:

- realPage;
- changedUrl;
- changedCanonicalHref;
- flipAtCanonicalHrefRead.

Internal state:

- armed = false;
- canonicalHrefReads = 0;
- drifted = false.

Expose:

- proxied Page;
- arm() which sets armed=true, canonicalHrefReads=0, drifted=false;
- optional diagnostic getters only for assertions/logging.

Page Proxy behavior:

1. For property url, return a function that returns changedUrl when drifted=true; otherwise return realPage.url().
2. For property locator, return a function that calls realPage.locator(selector,...args). If selector is exactly link[rel="canonical"], wrap that real Locator in the Canonical Locator Proxy described below; otherwise return the real Locator unchanged.
3. For every other Page property, use the real Page value. If callable, bind it to the real Page before returning it. This binding is mandatory so Playwright receiver/private state is preserved.

Canonical Locator Proxy behavior:

1. For getAttribute, return an async function that first calls the real Locator.getAttribute(name,...args) and records its real result.
2. If name is not href or armed=false, return the real result unchanged.
3. If armed=true and name is href, increment canonicalHrefReads.
4. When canonicalHrefReads reaches flipAtCanonicalHrefRead, set drifted=true.
5. If drifted=true after that decision, return changedCanonicalHref; otherwise return the real href.
6. For every other Locator property, delegate to the real Locator and bind callable values to the real Locator.

This helper MUST NOT modify the actual DOM, history, canonical element, browser driver, provider fixture HTML, global Playwright prototypes, clock, timers or production source. It is a deterministic source-view simulation around the production strategy.

The reason it is valid: both identity resolvers read canonical href and then page.url(). Flipping drifted during the selected canonical href read makes the immediately following page.url() return the matching changed route, so the strategy sees one coherent new identity rather than a route/canonical conflict.
