# Перенос единого архитектора Seller Agents

01_ASTRA_NEW_CHAT.md — полный стартовый промпт для нового диалога Astra с очень высокой глубиной рассуждения. Вставлять обычным текстом. Он восстанавливает роли, продукт, текущее состояние всех трёх линий и способ авторежима через Business Bridge.

02_REPORT_PREFIX.md — постоянный управляющий префикс к отчётам Codex. Вставить целиком в поле префикса отчёта Business Bridge для нового диалога, включить и установить интервал 1. Он предназначен Astra, а не исполнителю.

STATE.md — текущий cursor. На момент подготовки ждём terminal report I1-C1-R1. После получения и ревью его нужно актуализировать перед переходом; старый исходный C1 не является новым R1-результатом.

Владелец остановил оба прежних серверных потока. Принятие их ответственности не означает принятие B5: он остаётся REWORK_REQUIRED.

Промпты проверены на отсутствие fenced/indented code blocks. В ответах Astra кодовая форма разрешена исключительно для одного готового задания Codex. Для статусов, отчётов, JSON, примеров, цитат, промпта восстановления и этого префикса она запрещена.

references содержит исторические отчёты владельца, независимое C1-ревью, точный B5 CI failure и неизменённую полную документацию Business Bridge. Исторические формулировки в этих копиях не отменяют более поздние указания владельца и актуальный STATE. Документация Bridge является справочным вложением другого продукта, а не набором разрешений изменять Seller Agents или локальный Bridge.

Новые coding tasks, CI reruns и авторежим при подготовке этих файлов не запускались. Production-код и рабочие feature branches не изменялись.
