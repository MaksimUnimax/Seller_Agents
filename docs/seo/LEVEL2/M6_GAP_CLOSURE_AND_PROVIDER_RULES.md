- full-SERP feature representation on justified subset;

- bounded regional sensitivity where material;

- cross-query exact-URL/domain overlap QA.

If M4A has already produced a complete accepted pairwise overlap matrix from the same accepted M3 authority set, M6 reuses and verifies that artifact rather than recomputing it for ritual duplication.

NO_MATERIAL_CHANGE | ENRICH | REOPEN_TARGETED_GAP | HOLD.

Large data is never sampled to avoid Work.
