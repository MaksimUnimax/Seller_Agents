# LEVEL 2 — M12 Page Jobs, page specs and content system

Status: ACTIVE
Date: 2026-09-18
KW-002 analog: Step18 Page Jobs + Step19 deliverable usability

## Purpose

Turn final governed architecture into implementable page contracts without losing semantic evidence or product truth.

A page spec is not generic SEO copy. It is a task contract for one page job.

## Required inputs

- current PRODUCT_TRUTH;
- accepted M11 final page ownership/IA;
- accepted cluster authority;
- demand metrics/provenance;
- Search evidence;
- accepted AI deltas only where M10 says they matter;
- current site baseline.

## Required fields per indexable target page

- canonical planned URL / page role;
- physical action KEEP/OPTIMIZE/CREATE;
- primary query/semantic target + observed demand provenance;
- secondary queries + individual metrics/provenance;
- cluster/user task/intent;
- product promise boundary;
- own coverage;
- covered_elsewhere / anti-cannibalization boundary;
- expected content type/format/angle;
- H1 target state;
- Title target state;
- description guidance;
- required semantic blocks;
- required product evidence/demos/proof/trust;
- FAQ only where evidence supports user need;
- internal links in/out;
- parent/child IA relation;
- canonical/indexing state;
- schema eligibility;
- Alice/source-readiness notes where accepted;
- SEO priority HIGH/MEDIUM/LOW + textual basis;
- implementation state;
- source/evidence lineage.

## Quality boundary

Current Yandex quality guidance is used as a page-content gate:
expertise, usefulness, originality, meaningful completeness.

~~~text
KEYWORD PRESENCE != USEFUL PAGE
COMPETITOR WORDING != COPY SOURCE
UNIQUE TEXT != ORIGINAL VALUE
AI-GENERATED GENERIC TEXT != EXPERTISE
~~~

Originality means useful product-specific value: actual mechanics, examples, boundaries, data, screenshots/demos, expertise or clear unique explanation where available.

## Content scope

Do not prescribe unsupported claims, fake case studies, fake metrics, fake prices or capabilities.

Do not pad pages to word counts.

Do not create FAQ/schema blocks just because they are SEO conventions.

## Search/Alice relationship

Search task remains primary page job. Accepted M10 AI deltas can enrich:
- explanatory depth;
- source-ready factual blocks;
- security/API/entity clarification;
- supporting guide need;
- answerable subquestions.

No AI-specific page merely to manufacture AI value.
