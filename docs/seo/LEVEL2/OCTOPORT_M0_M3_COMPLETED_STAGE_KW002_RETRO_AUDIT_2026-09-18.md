- what was actually done well;
- what was weaker than hardened KW-002;
- which historical PASS states remain valid for their declared purpose;
- which retrospective debts must close before M7 Search-side Collection Freeze;
- which defects can be corrected from already durable evidence without provider replay.

Hard rule:

~~~text

-> PATCH ONLY THE MISSING CONTROL
-> REOPEN ONLY AFFECTED DOWNSTREAM DECISIONS
~~~
