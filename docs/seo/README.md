# SEO и семантика Октопорта

Статус: **SEO-S0 IN PROGRESS**.
Дата начала: 2026-09-16.
Рабочая ветка первого прохода: `docs/seo-semantic-foundation-2026-09-16`.
Исходный `main` на момент взятия работы: `16c0ac9b6aa9a72aa3100eb04f14bd74e4d6593a`.

Этот каталог — постоянная authority для органического поиска, семантического ядра и поисковой архитектуры публичного продукта **Октопорт / Octoport**. Техническое имя репозитория `Seller_Agents` не используется как целевой публичный бренд.

## Цель

Построить не набор «SEO-текстов», а доказуемую поисковую архитектуру продукта:

`product truth → seed hypotheses → Wordstat evidence → semantic universe → очистка → intent clustering → target/page roles → SERP verification → page specs → technical SEO → post-launch measurement`.

Структура сайта не считается окончательной до проверки реального спроса. Нельзя создавать посадочную страницу только потому, что формулировка кажется логичной. Нельзя назначать одной фразе несколько конкурирующих target pages без явного решения о канонической роли.

## Границы первого контура

Основной рынок первого семантического прохода — русскоязычный спрос вокруг продавцов Ozon/Wildberries и использования ИИ/нейросетей для работы с данными маркетплейсов. Основной источник частотности — Yandex Wordstat через принятый Yandex Wordstat Bridge. Технические SEO-правила проектируются поисково-агностично и не должны ухудшать Google или другие поисковые системы.

Первый проход не является рекламной кампанией и не определяет платную семантику Директа. Он может дать основу для неё позже, но текущая цель — органический поиск и информационная архитектура публичного сайта.

## Уровни доказательности

Каждый важный вывод в SEO-документах должен иметь один из статусов:

- `PRODUCT_TRUTH` — подтверждено действующей продуктовой документацией/решением владельца;
- `SEARCH_HYPOTHESIS` — рабочая гипотеза до внешней проверки;
- `WORDSTAT_OBSERVED` — получено из Wordstat с сохранёнными параметрами запроса и датой;
- `SERP_OBSERVED` — подтверждено анализом поисковой выдачи с датой и регионом/контекстом;
- `SEO_DECISION` — аналитическое решение о кластере, target page, приоритете или перелинковке с указанным основанием;
- `IMPLEMENTED` — реально внесено в публичный сайт и проверено в source/deploy surface;
- `MEASURED` — подтверждено post-launch данными индексации/показов/кликов/позиций.

Нельзя повышать `SEARCH_HYPOTHESIS` до `WORDSTAT_OBSERVED` или `SEO_DECISION` без соответствующей проверки.

## Неподвижные правила качества

- Частотность хранится рядом с конкретной фразой, а не только агрегатом кластера.
- Нулевая/низкая частотность не означает автоматическое исключение: брендовые, продуктовые и узкие high-intent запросы оцениваются отдельно.
- Высокая частотность не означает релевантность продукту.
- Кластеры строятся по интенту и SERP-совместимости, а не только по леммам.
- Каждая индексируемая target page имеет собственную зону покрытия и явно перечисляет, что должно ранжироваться на других страницах.
- Не создаём fake CREATE pages ради количества URL.
- Не публикуем возможности, которых нет в текущем или принятом launch scope.
- Не публикуем исторические цены `199/299` как текущую оферту.
- Не утверждаем, что публичная регистрация или полный browser/provider support уже запущены, пока это не стало доказанным фактом.
- Маскот и логотип поддерживают бренд, но не подменяют поисковый язык пользователя.
