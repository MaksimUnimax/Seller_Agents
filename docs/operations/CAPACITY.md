# Нагрузка и автономность

Это проектные бюджеты и способ измерения, не результат нагрузочного теста.

## Обычный путь

Команда и доставка требуют 0 обязательных запросов control plane.
Служебный обмен — при входе/активации, изменении магазина/привязки, обновлении допуска/конфигурации и редком переносе.
Фоновый служебный цикл примерно раз в час активной установки, с jitter и объединением мелких изменений. Он не создаётся на каждую вкладку/диалог.
Точное число HTTP запросов цикла зависит от refresh и состава endpoints; нельзя считать один логический цикл всегда одним запросом.

Пример расчёта: N активных установок, H активных часов в сутки, K фактических запросов на цикл.
Средний фон: N × H × K / 86400 запросов/с.
При 1000 установок, 8 ч и K=2 это примерно 0.19 запросов/с в среднем. Это не оценка пика, стоимости сервера или гарантированная производительность.
Дополнительно учитываются логины/OTP, запуск браузеров, административные действия, HTTP retry и monitors.

## Редкие сценарии

Pending reconcile создаёт backoff только затронутых установок. В отсутствие pending нет частого sync polling.
При массовом сбое ограничивать одну попытку на установку, jitter, максимальную пачку и server retry hints; не будить все диалоги отдельно.
Ограничить очереди, plaintext metadata size и relay payload; ошибка telemetry не блокирует auth.
Не копить отчёты/команды на сервере для согласования. Short transaction затрагивает одну binding, не весь аккаунт/реестр магазинов.

## Приёмка нагрузки

Измерить отдельно:
- startup/login burst и отправку OTP;
- bootstrap/refresh в обычном цикле;
- последние места регистрации при конкуренции;
- массовый возврат связи с pending reconcile;
- изолированный relay и browser health нагрузку;
- обычное исполнение при искусственно медленном/недоступном optional sync.

Метрики: p50/p95/p99 latency, ошибки, CPU/RAM, DB pool/lock time, event-loop delay, pending backlog, средний размер пачки и контрольные API calls per command.
Критерий изоляции: sync/health нагрузка не создаёт обязательного ожидания в обычном локальном пакете; базовый auth доступен при отказе optional reconcile.
Число «95% автономно» превращаем в эти наблюдаемые показатели; процент времени сам по себе не измеряет серверную стоимость.

Конкретный размер production host выбирается после этих измерений и известного числа активных установок, не по числу строк кода.
